## 设计与决定

- 保留模型包 v1 和旧 C ABI1。新增 IRS4BIN1 小端、无指针、带 CRC32 的执行描述 v1；权重按规划 arena 重排，元数据 JSON 仅供离线查看。
- C runtime 不解析 JSON，不执行 Python，不分配内存；调用方提供描述符/调用表和三个 arena。PC 独立程序通过 C 平台回调完成读取、分配、时钟、同步。
- C 后端 vtable 采用静态整链 query/execute/recover；默认桥接现有 ir_core，不自动回退。Python 适配器接入既有 StaticBackend、Session、SimDevice 和 TraceRecorder。
- C 独立追踪使用独立版本 JSON，标记主机单调时间、进度和同步；Python 运行时追踪继续使用现有格式，不能混淆两种文件。
- 范围：FP32/INT32、linear/add/relu、rank1—4，沿用已有算子能力；不绑定模型/量化，不宣称 RV32/板卡验证。
