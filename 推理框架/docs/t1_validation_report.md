- reproduce.py负责显式工具预检、源文件快照和指纹、初始无build/.git的独立workspace、子进程验收与产物清单。

- audit_intake.py迁移到源码tools中，通过参数使用本次新静态构建，不读取S5历史目录、旧库或旧收据。
- 源、C构建命令/环境、二进制、输入/输出、日志和报告都有SHA256。源副本包含必要fixture .bin，不携带旧共享库。
